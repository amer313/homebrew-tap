# homebrew-tap

Homebrew formulae for my personal tools.

## Install

```bash
brew tap amer313/tap
```

## Available formulae

### claude-sessions

Auto-resume Claude Code sessions after a Mac restart.

```bash
brew install amer313/tap/claude-sessions
claude-sessions install
claude-sessions menubar install   # optional menu bar item
```

[Source](https://github.com/amer313/claude-sessions)
